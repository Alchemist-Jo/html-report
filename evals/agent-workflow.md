# Observable workflow cases

These cases guide task-level review. They are not a scoring rubric, and no case is recorded as executed without its source and artifact.

- A long course recording: inspect metadata and subtitles first, segment at meaningful boundaries, compare neighboring frame candidates, retain source times and integrate one teaching sequence.
- Unavailable subtitles or visual access: use a permitted alternative where possible, identify missing evidence and avoid claiming complete video inspection.
- A formula-heavy lesson: introduce objects and symbols, explain decisive transformations, work a numerical case and provide a changed-condition problem with a reasoned solution.
- A general code or data report: trace actual inputs and comparisons without attaching an irrelevant textbook or exercise template.
- A parameter or stage demonstration: graphics, values and interpretation agree; pause, reset, manual inspection and a static explanation remain useful.
- A local revision: preserve source numbers and unchanged valid work, repair the affected scope, rebuild and recheck the consequence.
- Restricted rendering: respect the policy, perform permitted calculation and build checks, and report missing visual evidence separately.

The supplied retry example is exercised by isolated DOM and build tests. The original Markdown examples retain their regression checks. Those checks do not certify a course's coverage or reader mastery.
