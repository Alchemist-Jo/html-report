# 视频取材与系列课程

输入包含视频时读取。沿用 youtube-render-pdf 的取材标准，按 HTML 调整来源呈现。

## 获取材料

先核实标题、作者、发布日期、时长、封面、章节、字幕轨和可用分辨率。系列课程同时核实讲次、视频列表和与官方讲义的关系，区分“讲义已发布”与“录播可用”。仅检查了部分讲次时直接说明范围。

使用平台页面、官方课程页与现有下载工具。字幕优先人工轨，其次匹配语言的自动轨。保留时间戳，纠正 ASR 时依靠上下文、画面或音频。没有字幕时，可用现有音频转录能力，保留片段时间并说明转录来源。材料无法获取时说明缺口；不能拿外部摘要替代视频检查。

现有 yt-dlp 可先执行只读探测，再按输出选择字幕和下载格式：

~~~sh
yt-dlp --dump-single-json --skip-download "VIDEO_URL" > video.json
yt-dlp --list-subs --list-formats "VIDEO_URL"
~~~

若工具不支持平台或探测失败，检查官方课程页、平台元数据或用户提供的本地材料。拿到时间字幕和视频后再用 ffmpeg 批量生成所需区间的候选，避免先下载整套课程再判断是否可用。

原封面放在教材开头。使用元数据提供的较高清版本；有官方封面时不随意换成视频帧。用户已提供参考设计不代表其正文或图像可作为课程证据。

先探测实际可下载格式，再选择适合读清课件的最高可用分辨率。需要观察视频画面时获取本地视频或相应片段。默认保存元数据、时间字幕、封面和选中截图；庞大原视频不纳入最终分享包。

## 分段与覆盖

视频时长超过 20 分钟或字幕超过 300 条时分段。优先章节，其次连贯概念或时间窗口。邻接段落的解释跨边界时保留少量重叠，汇总时去重。

每段留下简短记录：教学目标、核心主张、机制步骤、公式/代码、所需图示及时间、歧义。系列课程可共享术语与概念索引，避免在每讲重复完整背景。

正文按教学依赖重组，并提供对应讲次与时间定位。保留高信息密度的例子、示范、重要讨论和结尾总结。省略广告、寒暄、重复闲聊。对话只有原措辞确有教学价值时才短引，标说话人和时间，随后解释其意义。

## 关键帧

1. 从时间字幕定位确切的概念区间，在区间内及边界附近生成多个密集候选，初筛优先减少遗漏。
2. 联系表帮助定位，最终选择必须实际查看候选原图或裁剪图。不能依据文件名、邻近字幕或 OCR 推断画面含义。
3. 比较临近候选，确认正文提到的元素已经全部出现。逐步揭示的幻灯片、白板和动画优先选最终完整可读状态。
4. 检查标注、公式和结构可读性。必要时裁剪、放大或拆成数幅图。中间状态只有在教授不同步骤时保留。
5. 原候选按时间命名，视觉确认后才能赋予语义文件名。过渡、模糊或不完整画面继续搜索。

图片数量按解释需要决定。必要画面不能因固定配额被删掉，重复和低信息画面应省去。

## HTML 来源呈现

每张视频帧或裁剪图使用 figure 和 figcaption。图注紧邻图片，写讲次、字幕定位区间及实际截图时间，例如“第 2 讲，定位区间 00:12:31–00:12:46，截图 00:12:42”。原始截图时间与定位区间分别记录，不能把整个区间写成画面持续时长。

附对应视频或平台支持的时间链接。未验证精确跳转时保留文字时间与原视频链接，不声称链接一定能定位。课程多分 P 时同时记录视频 ID 和分 P。

封面标注官方封面。重绘图写清“根据课程内容重绘”；补充示例或交互写明其假设，避免混同原视频画面或实测数据。

需要提取多个帧时，让现有命令批量执行；不要让模型逐帧生成重复命令。保留必要候选与选中素材，最终教材只嵌入选中的资源。
